# Tesla Motion

An independent Tesla showroom concept built with HTML, CSS, JavaScript and Three.js.

## Run locally

Serve `tesla-motion/dist/` with a static HTTP server, for example:

```sh
python -m http.server 8000 --directory tesla-motion/dist
```

Open http://localhost:8000. No npm install or build is required.

The editable application source is in `tesla-motion/dist/`. Asset credits and licenses are included in `credits.html` and `assets/`.

This project is not affiliated with Tesla. Booking and configuration forms are demonstrations.

Local browser profiles, QA screenshots, downloaded tools and release archives are excluded from Git.
